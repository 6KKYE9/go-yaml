# go-yaml

一个轻量的 YAML 字段查询工具，不引入任何第三方库。用点路径取出嵌套的值，
适合在脚本里从配置文件抠某个字段，或者 CI 里检查部署清单。

零依赖，只用 Go 标准库。

## 用法

```
# 从文件查
go-yaml -p server.port config.yaml

# 从管道查
cat config.yaml | go-yaml -p items.0.name

# 不写路径，打印顶层所有键
go-yaml config.yaml
```

路径语法：
- `a.b.c` 取嵌套键值
- `a.0.b` 列表下标访问，第 0 项的 b 字段

## 支持的常见写法

- 缩进层级（空格或 tab 都行）
- `key: value` 键值对
- `- 项` 列表，列表项可以是标量，也可以是带 key 的映射（`- name: foo`）
- 行内列表 `key: - a - b`
- `#` 注释（引号里的值含 `#` 不会被误删）
- 引号包裹的值（自动去引号、处理 `\"` 转义）

## 限制

不是完整的 YAML 规范实现，目标是覆盖配置文件里 90% 的常见结构。
多行字符串、锚点引用、复杂流式写法这类暂不处理。
